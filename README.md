# zerocoder-odxx — алгоритмы и структуры данных

Блок «Основы алгоритмов и структур данных»: всё на чистом Python, без внешних зависимостей.

## Содержимое

- **`od01/palindrome.py`** — проверка палиндрома методом двух указателей, с нормализацией строки и пошаговым разбором алгоритма в комментариях.
- **`od02/`** — структуры данных, реализованные с нуля: стек (`stack.py`), очередь (`queue.py`), дерево (`tree.py`), граф (`graph.py`).
- **`od03/`** — четыре сортировки (пузырьком, выбором, вставками, быстрая) и измерительный стенд:
  - `sort_stats.py` — версии сортировок со счётчиками операций;
  - `compare_sorts.py` — сводный прогон: проверка корректности против эталонного `sorted()` на коварных случаях, замеры времени на разных типах данных, таблица счётчиков (чистая работа алгоритмов без питоновских накладных расходов), сверка с теоретической асимптотикой и намеренный краш-тест быстрой сортировки с pivot = первый элемент.

В `notes/` — HTML-заметки (гамма-функция, граф Захари).

## Запуск

Любой скрипт запускается напрямую, зависимостей нет:

```bash
python od03/compare_sorts.py
```
